# Part B — Quiz Answers

1. **C** — Abstraction hides how operations work and exposes what they do.
2. **C** — An abstract class cannot be instantiated directly.
3. **B** — A concrete subclass must implement inherited abstract methods or be declared abstract.
4. **C** — An abstract method cannot be private because subclasses must implement it.
5. **C** — Interface fields are implicitly `public static final`.
6. **C** — A class can implement any number of interfaces.
7. **D** — Implemented interface methods must be public.
8. **C** — Interfaces avoid multiple inheritance of class instance state, though conflicting default methods need resolution.
9. **D** — Conflicting interface default methods must be overridden, or compilation fails.
10. **B** — An abstract class constructor runs when a subclass instance is created.
